# PIG RUSH!!!!! 🐷
Hello and welcome to my game *oink*.

# About Game 🎮
1. Game was built in Godot
2. Multiple sprites were taken from Itch and some were made by hand
3. The Main themes of the game are: Pigs, Everything has a cost

# Functionality 👾
1. Use W,S,A,D or Arrow keys to move
2. Collect the pigs around the map
3. Sell the colected pigs to the butcher
4. EVERYTHING costs coins
5. ***GOAL***: Make the Most money!
6. Enjoy the Game
